# Python Drills

Practice problems with test cases for the L2E cohort. each problem has a spec, a stub to fill in, and a test file.

## Structure
- `drills/`: weekly practice problems with specs, starter stubs, and test suites.
- `solutions/`: reference solutions added at the end of each week.

Run a test: `cd drills/week1/01-fizzbuzz` then `python test_fizzbuzz.py`. you should see `BIM!!!` when everything passes.
